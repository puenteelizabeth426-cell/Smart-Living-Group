# Smart Living Group — Next.js Website

This is a Vercel-ready production website for Smart Living Group.

## Upload to GitHub
Upload the whole folder contents to your GitHub repository:
- app/
- public/
- package.json
- next.config.mjs
- tsconfig.json
- next-env.d.ts

## Deploy on Vercel
1. Go to Vercel.
2. Import the GitHub repository.
3. Framework should show Next.js.
4. Click Deploy.

## Update before launch
Replace:
- Phone number
- Email
- Real project photos
- Logo
- Google review link
- Domain
